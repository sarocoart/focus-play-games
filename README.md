# 포커스 플레이 (Focus Play)

시니어를 위한 눈 운동 놀이 콘텐츠 모음입니다. 화면 속 캐릭터를 손 조작 없이 **눈으로만 따라가는** 게임 10종으로 구성되어 있습니다.

## 게임 목록

| 파일 | 게임 | 방식 |
|---|---|---|
| index.html | 홈 (게임 선택 화면) | — |
| baby.html | 아기의 과일 모험 | 좌우·위아래 왕복 |
| puppy.html | 강아지의 간식 산책 | 좌우·위아래 왕복 |
| space.html | 로켓의 별 여행 | 좌우·위아래 왕복 |
| chicken.html | 마당의 닭 쫓기 | 좌우·위아래 왕복 |
| sparrow.html | 참새와 방앗간 | 좌우·위아래 왕복 |
| bus.html | 추억의 완행버스 | 좌우·위아래 왕복 |
| stream.html | 개울가 붕어 잡기 | 좌우·위아래 왕복 |
| disco.html | 추억의 고고장 | 좌우·위아래 왕복 |
| yeot.html | 엿장수 마음대로 | 좌우·위아래 왕복 |
| random.html | 아장아장 아기 따라가기 | 사선 포함 자유 이동 |

## 특징

- 별도 설치 없이 브라우저에서 바로 실행 (순수 HTML/CSS/JS, 외부 의존성 없음)
- 게임 맞춤 설정: 개인에 맞춰 움직임 방향·진폭을 조절
- 오리지널 일러스트 캐릭터 (모든 기기에서 동일하게 표시)
- 시니어 친화 UI: 큰 글씨, 간단한 조작

## 안내

본 게임은 의료기기가 아니며, 질병의 진단·치료·예방을 목적으로 하지 않는 오락용 콘텐츠입니다. 화면 속 움직임을 따라보며 눈을 움직이는 활동을 돕는 놀이형 콘텐츠입니다.
