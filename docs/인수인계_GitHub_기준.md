## 1. 새 대화·새 도구에서 작업 시작하는 법

1. GitHub 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** 으로 최신 원본을 받아
2. 그 zip + 이 가이드를 대화에 올리고 시작
3. 붙여넣을 문장:
   > "focus-play-games GitHub 프로젝트를 기준으로 수정해 주세요. 첨부한 zip이 저장소 최신 원본입니다. 인수인계 가이드의 규칙(최소 범위 수정, 변경 파일 보고, 무변경 체크섬 증명, 검증 2회, 표현 안전)을 지켜주세요."

⚠️ 여전히 금물: 파일 없이 "다시 만들어줘" — 재생성은 버그 수정 소실의 주범.

## 2. 작업 원칙 (사용자 확정)

- GitHub 저장소를 기준으로 수정한다. Netlify 기준 작업 금지
- 프로젝트 구조를 유지하면서 **필요한 파일만** 수정한다
- 변경은 기존 기능이 깨지지 않도록 **최소 범위**로 한다
- 수정 완료 시 **변경된 파일 목록과 수정 내용을 명확히 보고**한다
- 무변경 파일은 체크섬으로 증명, 검증 2회(문법+렌더링/시뮬레이션), 5대 버그 점검, 금지어 감사 유지

## 3. 결과물 전달 → 반영 방법

- AI는 GitHub에 직접 접속·푸시할 수 없으므로, **수정된 파일들만 다운로드 카드**로 전달 + 변경 보고서(MD)
- 사용자는 GitHub 웹에서: 저장소 → **Add file → Upload files** → 수정 파일 드래그 → Commit
  (같은 이름 파일은 자동으로 새 버전으로 교체됨)
- 커밋하면 Vercel이 1~2분 내 자동 배포 → 배포 후 `Ctrl+F5` 확인
- 팁: Claude Code를 쓰면 이 업로드 과정까지 AI가 직접 커밋·푸시로 처리 가능

## 4. 현재 파일 구성 (v16 시점, 12개)

index.html(홈) + 게임 10종(baby·puppy·space·chicken·sparrow·bus·stream·disco·yeot = v1 왕복 / random = v2 랜덤) + README.md

캐릭터 현황: 오리지널 일러스트(charSVG 내장) — 과일모험 아기↔딸기(1.5배·흰원) / 강아지↔뼈다귀(1.5배·흰원) / 고고장 남↔여(2배) / 아장아장 아기↔곰돌이(흰원). 로켓·추억5종은 기존 유지.
